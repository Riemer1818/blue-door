# Market

The world outside the repo: who else is doing this, who would pay, what the rules are, and what
the underlying science actually supports.

## What's here

- **[eln-landscape/](eln-landscape/)** — the ELN / lab-software competitive landscape, scanned
  August 2026. A folder, not a page: [narrative read](eln-landscape/README.md),
  [structured vendor data](eln-landscape/vendors.yaml) you append to, and
  [sources](eln-landscape/sources.md). Start here.

## Still to write

  moat as real and EU sovereignty as a wedge; both claims need an actual regime write-up behind
  them before we build on either.
- `science/` — the literature the product rests on, one file per thread of evidence.

## Two rules that matter more here than anywhere else

1. **Date everything.** A competitor's pricing page is a snapshot, not a fact. Funding figures
   are last-disclosed, never current.
2. **Quote, don't paraphrase.** Especially for science and regulation — the paraphrase is always
   more confident than the source. Copy the sentence you are relying on, then interpret it
   separately and label the interpretation.

Conventions for the collection as a whole are in [../README.md](../README.md).
